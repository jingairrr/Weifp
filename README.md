## 关于Weifp

## 功能
可以调整亮度、对比度、高光、阴影以及HSL、曲线、直方图等也可以用它绘制简单的图案，可以读取RAW基于LibRaw实现

## About Weifp

Weifp is a Java-based image editor for Android.

## Features

Adjust brightness, contrast, highlights, shadows, as well as HSL, curves and histogram. You can also draw simple graphics with it, and it can read RAW files via LibRaw.

## Build

Android Studio or AIDE is recommended to build this project.

Source code is in `Weifp-10an05-source.zip`.
